## По пунктам

### 1. На стартовом экране не работали стрелки
Picker слушал только `Ctrl-n/Ctrl-p`. Добавил в `Key` варианты
`Up/Down/Left/Right`, прокинул их через `event_map` и `parse_keys`
(`<Up>/<Down>/<Left>/<Right>`, заодно `<Space>`). Теперь в пикере работают
стрелки `↑/↓`, в дереве/бэклинках — `↑/↓` + `j/k` + `w/W/b/B`.

### 2. Вид «ideas» (скриншот)
Картинка `[Image #1]` до меня в этой сессии **не дошла** (не приложилась к
контексту). Рендер markdown я не трогал — если есть конкретный дефект отрисовки,
пришли скрин ещё раз или опиши словами, поправлю точечно.

### 3. Не было понятно, как снова вызвать fuzzy
Fuzzy-поиск был на `Ctrl-p`, но это негде было увидеть. Теперь к нему ведут
**три** пути: `Ctrl-p`, пункт меню **Find note** (`<Space> f`) и help (`F1`/`?`).

### 4. Подсказки и помощь
- `F1` или `?` → **модалка помощи** со списком хоткеев.
- Внизу модалки надпись: `enter: instruction   shift+enter: developers`.
- `Enter` раскрывает `docs/manual.md`, `Shift+Enter` — `docs/developers.md`.
- Оба файла **лежат в репозитории vi-book** и вкомпилированы в бинарь
  (`include_str!`), а не в волте пользователя — открываются как read-only вью.

### 5. nvim-like меню и `<leader>`
- Концепция `<leader>` (по умолчанию **пробел**, настраивается).
- Лидер открывает **which-key-меню**: Find note / New note / Toggle read-edit /
  Tree / Backlinks / Today / Write / Help / Quit.
- Навигация в меню: стрелки/`j`/`k` + `Enter`, либо сразу буква пункта; `Esc` —
  закрыть.

### 6. Кастомизация через плагины
В Lua добавлены опции и API:

```lua
vibook.opt.leader = " "             -- клавиша меню
vibook.opt.insert_escape = "jj"     -- выход из insert (по умолчанию jj; "" — выкл)
vibook.opt.menu_position = "center" -- "bottom" (по умолчанию) | "center" модалка
vibook.menu_item("g", "Scratch", ":new scratch") -- свой пункт меню
```

- `jj → Esc` включён **по умолчанию** (как просили), без таймеров: при наборе
  последовательности символы откатываются и происходит выход в normal.
- Позиция меню переключается между нижней панелью и центральной модалкой.

### 7. Установка и запуск (вместо `with-env ... VIBOOK_CONFIG=...`)
- `./install.sh` — POSIX-sh, работает из любой оболочки: собирает release,
  кладёт бинарь в `~/.local/bin` (или `$VIBOOK_BIN`/`$PREFIX`), создаёт дефолтный
  `~/.config/vi-book/init.lua`, печатает подсказку по PATH для **bash/zsh/fish/
  nushell**.
- **Env-переменные больше не нужны**: конфиг по умолчанию читается из
  `~/.config/vi-book/init.lua` (`VIBOOK_CONFIG` остаётся как override).
- Поведение `vi-book` как у `nvim`:
  - `vi-book` / `vi-book ~/notes` / `vi-book note.md`;
  - папка **без .md** → стартовый экран «no notes here» с предложением создать
    заметку (`n`) или daily (`d`);
  - папка с .md → список заметок (fuzzy-пикер).
- Создание заметок: команда `:new <name>` (создаёт `<name>.md`, переиндексирует,
  открывает).

### 8. Файл открывается в read-режиме по умолчанию
`App::load` теперь ставит `View::Read` (раньше `Edit`). `i` входит в правку,
`Esc`/`jj` выходит, `Ctrl-t` переключает.

### 9. Стрелки и w/W b/B везде
- **Стрелки** работают в normal, insert, read, пикере, дереве, меню.
- В editor `w/W b/B` уже были (vim). Добавил их в **read-режим**:
  - `w/b/e` — по словам (переиспользую `vim::word` поверх рендера);
  - `W/B` — по **блокам**: заголовок / абзац / пункт списка (то, что ты назвал
    «элементом»).
- В меню/дереве «элемент» = пункт, поэтому там `w/W/b/B` двигают выбор.
- В read-режиме `Enter` переходит по `[[ссылке]]` под курсором.

## Архитектура изменений

Новые модули (все ≤200 строк, SRP):

| Файл | Ответственность |
|------|-----------------|
| `ui/router.rs` | единая маршрутизация клавиш `handle(app, key)` |
| `ui/menu.rs` | which-key-меню + стартовый экран пустого волта |
| `ui/help.rs` | биндинги + встроенные manual/developers |
| `ui/actions.rs` | open_menu / menu_key / help_key / open_doc / toggle_view |
| `ui/read_motion.rs` | w/b/e и W/B для read-режима |
| `docs/manual.md`, `docs/developers.md` | документация (в бинаре) |
| `install.sh` | кроссшелловая установка |

Ключевые правки: `Key` (+стрелки), `event_map`/`key.rs` (парсинг),
`vim/normal.rs`/`motion.rs` (стрелки-движения), `vim/insert.rs`+`editor.rs`
(`insert_escape`, стрелки), `ui/app.rs` (поля, default read, стартовый экран),
`ui/input.rs` (`global_nav`, навигация в пикере/панели), `ui/plugin.rs`
(`apply_opts`), `lua/config.rs`+`host.rs` (menu_item / menu_items).
